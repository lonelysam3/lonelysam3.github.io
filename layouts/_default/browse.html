{{- /* ========================================================================== browse.html — 内容总览页，把分类与标签并排呈现（C 组整合） -------------------------------------------------------------------------- 为什么要做这一页，而不是把两个分类法合并： 「分类」与「标签」在 Hugo 里是两套独立的 taxonomy，各自有 URL 前缀 （/categories/ 与 /tags/）。真要把它们合并成一套，必须 (a) 改 hugo.yaml 的 taxonomies 配置， (b) 迁移所有文章的 front matter， (c) 承担旧 URL 全部失效的代价（/tags/xxx/ 会 404）。 收益是「少一个页面」，代价是既有链接全断——不划算。 真正的痛点是【割裂】：读者想知道「站里都有些什么」时，得在分类页和标签页 之间来回跳。所以这里提供一个总览页：两者并排、都带计数与最近文章，并说明 各自的语义（分类=栏目，互斥；标签=关键词，自由叠加）。原有 taxonomy 页面 保留不动，链接不会失效。 ========================================================================== */ -}} {{- define "main" }} {{- $posts := where site.RegularPages "Type" "in" (site.Params.mainSections | default (slice "posts")) }}

    {{- with first 3 .Pages }}
      {{- range . }}

      • {{ end }}
    {{- end }}
    • {{- end }}
{{- else }}

{{- end }}

    {{- range .ByCount }}

标签组合

{{- $maxT := 0 }}{{ range .ByCount }}{{ if gt .Count $maxT }}{{ $maxT = .Count }}{{ end }}{{ end }}

    {{- with first 3 .Pages }}
      {{- range . }}
    • {{ .LinkTitle }}

    {{- end }}
